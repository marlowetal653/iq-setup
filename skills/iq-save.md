Save all current work and back it up to GitHub.

Steps:
1. Run `git status` to see what changed
2. If there's no git repo yet, initialize one:
   - `git init`
   - Create a GitHub repo with `gh repo create` (ask the student for a name)
   - Set it as the remote
3. Stage all changes: `git add .`
4. Look at the diff to understand what changed
5. Auto-generate a clear, descriptive commit message based on the changes
6. Commit the changes
7. Push to GitHub: `git push` (use `git push -u origin main` if this is the first push)
8. Tell the student: "Your work is saved and backed up to GitHub."
9. Provide a link to their repo on GitHub so they can see it
