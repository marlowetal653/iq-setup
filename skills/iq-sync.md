Get the latest version of the code and update dependencies.

Steps:
1. Run `git pull` to get the latest changes from GitHub
2. If there are merge conflicts, resolve them automatically or explain to the student what happened
3. Check if `package.json` changed — if it did, run `npm install` to update dependencies
4. Run the dev server briefly to make sure everything still works
5. Tell the student what changed in plain language (e.g., "3 files were updated with new features")
