Guide for designing and improving the visual appearance of your app.

Steps:
1. Run /iq-preview to see the current state of the app

2. Ask the student:
   - "What would you like to improve visually? (e.g. the whole look and feel, a specific page, the colors, the layout)"
   - "Do you have a design reference? (a Dribbble link, a screenshot, a site you love the look of)"
   - "What are your brand colors? If you have hex codes, share them. If not, describe the vibe — e.g. 'clean and minimal', 'bold and colorful', 'professional and dark'"

3. If they share a design reference URL, open it and study the:
   - Color palette
   - Typography (font styles, sizes, weights)
   - Spacing and layout patterns
   - Component styles (buttons, cards, inputs)

4. Plan the design changes and confirm with the student before touching code:
   "Here's what I'm going to change: [list]. Anything you'd like to adjust before I start?"

5. Apply changes in layers:
   - First: global styles (colors, fonts, background)
   - Then: layout and spacing
   - Then: individual components (buttons, cards, forms, navigation)

6. After each layer of changes, run /iq-preview and ask: "Here's how it looks. Does this feel right? What would you like to tweak?"

7. Iterate until the student is happy

8. Run /iq-push to commit the final design with a clear commit message
